Weather App is a web application for displaying the current weather and a 5-day
forecast for a selected city or based on the user's geolocation. The app is
built with a modern frontend stack and demonstrates working with APIs and
dynamic data rendering.

## 🛠 Technologies:

HTML, CSS, JavaScript — for structure, styling, and app logic

Vite — modern bundler and development server for fast project startup

Axios — for making HTTP requests to external APIs

IziToast — library for beautiful notifications

OpenWeather API — for fetching up-to-date weather data

## ⚡ Key Features:

Get the current weather for a chosen city or via geolocation

View a 5-day forecast with hourly details

Interactive "more info" buttons to show hourly forecasts for the selected day

Horizontal scrolling for the forecast with highlighting of active elements

Display charts for temperature, humidity, wind speed, and pressure

Save the last selected city in sessionStorage for quick access
